# Mermaiden

Mermaiden builds deterministic Mermaid source from typed Python diagram models. Callers work with diagram concepts and
validated commands; Mermaid text is an output boundary rather than the data model.

Start with [Create a sequence diagram](tutorials/create-a-sequence-diagram.md). Use the
[how-to guides](how-to/index.md) when you already know the outcome you need, and read the
[explanations](explanation/index.md) for the reasoning behind typed diagrams, transactions, snapshots, and rendering.

The [architecture and ownership map](architecture/index.md) records dependency direction and canonical implementation
authorities. The [glossary](glossary/index.md) fixes Mermaiden's vocabulary, while the
[reference](reference/index.md) gives exact CLI, generated contract, and Python API details.
