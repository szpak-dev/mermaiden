# Tutorials

Tutorials lead through complete Mermaiden workflows with visible results.

- [Create a sequence diagram](create-a-sequence-diagram.md) discovers a diagram contract, applies an atomic batch,
  persists the result, and renders Mermaid source.
- [Build a contract-driven adapter](build-a-contract-driven-adapter.md) discovers command schemas, rejects an unsafe
  request without changing state, and completes the same request once its references are valid.
